# B1.2 · 4.3 — Быстрее, выше, сильнее

Theme: kinds of sport, athletes.
Grammar: the superlative degree (-ейш/-айш); comparative (review); motion verbs without prefixes; motion verbs with prefixes пере-, под-, от-, про-, при-, у-.

---

## 1. Superlative degree (превосходная степень)

| Type | Formation | Example |
|---|---|---|
| **Compound (usual)** | **са́мый** + adjective (both decline) | **са́мый** бы́стрый спортсме́н; в **са́мой** интере́сной кни́ге |
| **Suffixal** (bookish) | **-ейш- / -айш-** (after г,к,х) | нове́йший, сильне́**йш**ий, велича́**йш**ий, широча́**йш**ий |
| **наиболее / наименее** | + adjective | **наибо́лее** ва́жный результа́т |
| **comparative + всех/всего** | predicate "most of all" | Он бе́гает **быстре́е всех**. Э́то **важне́е всего́**. |

- Он — **са́мый** молодо́й чемпио́н. · Э́то **велича́йший** спортсме́н в исто́рии.
- Она́ пры́гает **вы́ше всех**.

## Comparative (review)
Simple **-ее/-е** (быстре́е, вы́ше, сильне́е); compound **бо́лее/ме́нее +**; "than" = **чем** + nom or **genitive**; **чем…, тем…**. (See 4.2.)

## 2. Motion verbs without prefixes

Unprefixed pairs — **determinate** (one direction / now) vs **indeterminate** (multidirectional / habitual):

| Determinate | Indeterminate | Meaning |
|---|---|---|
| идти́ | ходи́ть | go (on foot) |
| е́хать | е́здить | go (by vehicle) |
| бежа́ть | бе́гать | run |
| лете́ть | лета́ть | fly |
| плыть | пла́вать | swim/sail |
| ползти́ | по́лзать | crawl |
| нести́ | носи́ть | carry |
| везти́ | вози́ть | transport |
| вести́ | води́ть | lead |

- Пти́цы **летя́т** на юг. *(now, one direction)* ↔ Пти́цы **лета́ют** высоко́. *(in general)*
- Спортсме́н **бежи́т** к фи́нишу. ↔ Он **бе́гает** ка́ждое у́тро.

## 3. Motion verbs with prefixes

Prefixes turn imperfective **indeterminate** verbs into **perfective** (and give a new imperfective from the determinate stem). Core prefixes:

| Prefix | Meaning | Example |
|---|---|---|
| **при-** | arrival (to) | прийти́ / приезжа́ть — прие́хать: Он **прие́хал** во́время. |
| **у-** | departure (away) | уйти́, уе́хать: Она́ **уе́хала** из го́рода. |
| **пере-** | across / over | перейти́, перее́хать: **перейти́** доро́гу; **перее́хать** в но́вый дом. |
| **под-** | approach (up to) | подойти́, подъе́хать: **подойди́** ко мне. |
| **от-** | moving off / away from | отойти́, отъе́хать: **отойди́** от кра́я. |
| **про-** | through / past / a distance | пройти́, прое́хать: **пройти́** ми́мо; **проплы́ть** киломе́тр. |

> [!tip] Aspect with prefixes
> A prefix + a **determinate** stem = **perfective** (прийти́, пробежа́ть). The matching **imperfective** is built from the **indeterminate** stem (приходи́ть, пробега́ть). So: приходи́ть / прийти́, уезжа́ть / уе́хать, переплыва́ть / переплы́ть.

## Connectors & useful constructions

- **бы́стрее, вы́ше, сильне́е** — the Olympic motto (*faster, higher, stronger*).
- **пры́гнуть вы́ше головы́** — *to go above and beyond (do the impossible)*.
- **ста́вить / поби́ть реко́рд** — *to set / break a record*; **оде́рживать / одержа́ть побе́ду** — *to win a victory*.
- **боле́ть за** (+ *acc*) — *to support (a team)*.
