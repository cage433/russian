# B1.2 · 4.1 — Живём один раз

Theme: money, shopping, world currencies.
Grammar: genitive plural; numbers (numerals) in all cases.

---

## 1. Genitive plural (родительный падеж множественного числа)

The trickiest plural. Main patterns:

| Gender / ending | Gen. pl. ending | Examples |
|---|---|---|
| Masc. hard consonant | **-ов** | до́ллар → до́лларов; рубль → рубл**е́й** (soft → -ей) |
| Masc. -й / -ь | **-ев / -ей** | музе́й → музе́**ев**; секре́т → секре́т**ов** |
| Fem. -а | **-∅** (zero, often + fleeting vowel) | кни́га → книг; де́вушка → де́вуш**ек** |
| Fem. -я / -ь | **-ь / -ей** | неде́ля → неде́ль; ночь → ноч**е́й** |
| Neut. -о | **-∅** | сло́во → слов; окно́ → о́кон (fleeting о) |
| Neut. -е / -ие | **-ей / -ий** | мо́ре → мор**е́й**; зда́ние → зда́н**ий** |

> [!tip] Zero-ending → fleeting vowel
> When the ending is zero and the stem ends in a consonant cluster, insert **-о-/-е-**: де́вушка → де́вуш**е**к; окно́ → о́к**о**н; ку́кла → ку́к**о**л.
> Irregulars: челове́к → **люде́й**; ребёнок → **дете́й**; друг → **друзе́й**; де́ньги → **де́нег**.

Genitive plural is required after **5+, много/мало/несколько, нет**: пять до́лларов, мно́го де́нег, нет книг.

## 2. Numerals in all cases + noun agreement

### Number + noun (nominative)
| Numeral | Noun form |
|---|---|
| **1** (оди́н/одна́/одно́) | **nominative singular** — agrees in gender: оди́н рубль, одна́ мину́та |
| **2, 3, 4** (два/две, три, четы́ре) | **genitive singular**: два рубля́, три мину́ты, четы́ре го́да |
| **5 – 20, and …0** | **genitive plural**: пять рубле́й, де́сять мину́т, два́дцать лет |
| compound ending in 1/2-4 | as for 1 / 2-4: два́дцать оди́н рубль; три́дцать два рубля́ |

### Declension
- **оди́н** declines like an adjective and agrees with the noun in case: **одного́** рубля́, с **одни́м** рублём.
- **два/две, три, четы́ре** decline: двух, трём, четырьмя́…; the noun goes into the **same** oblique case, plural: о **двух** рубля́х, к **трём** дома́м.
- **пять–два́дцать, три́дцать…** decline like fem. -ь nouns: пяти́, пятью́; the noun is plural in the same case: о **пяти́** рубля́х.

- Он заплати́л **пятью́ ты́сячами** рубле́й. · Мы говори́ли о **трёх** ва́жных ве́щ**ах**.

## Connectors & useful constructions (money idioms)

- **броса́ть де́ньги на ве́тер** — *to throw money away*; **лёгкие де́ньги** — *easy money*.
- **своди́ть концы́ с конца́ми** — *to make ends meet*; **жить на широ́кую но́гу** — *to live large*.
- **копе́йка рубль бережёт** — *take care of the kopecks…*; **купа́ться в деньга́х** — *to be rolling in money*.
- **сто́ить копе́йки** — *to cost next to nothing*; **бить по карма́ну** — *to hit the wallet*.
- **живём оди́н раз** — *you only live once*.
