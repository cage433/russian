# B2.1 · 2.1 — Не откладывай на завтра то, что можешь сделать сегодня

Theme: time management, stress, negative emotions & feelings, household chores.
Grammar: time prepositions за / на / через; prepositions вне / внутри; verbs + к + dative; verbs with the prefix пред-.

---

## 1. Time prepositions: за, на, через

| Question | Preposition | Meaning | Example |
|---|---|---|---|
| **за како́е вре́мя?** | **за** + *acc* | the time it takes to complete an action | Я могу́ погла́дить две руба́шки **за** 5 мину́т. |
| **за ско́лько до …?** | **за** + *acc* … **до** + *gen* | how long *before* an event | **За** два часа́ **до** сна не смотри́те в экра́н. |
| **на како́е вре́мя?** | **на** + *acc* | planned duration ("for") | Я уезжа́ю в Герма́нию **на** два го́да. |
| **че́рез како́е вре́мя?** | **че́рез** + *acc* | after an interval ("in / after") | Я позвоню́ тебе́ **че́рез** час. |
| **на ско́лько ра́ньше / по́зже?** | **на** + *acc* | by how much earlier/later | Он опозда́л **на** 5 мину́т. Рейс заде́рживается **на** 40 мину́т. |

> [!tip] за vs на vs через — the classic confusion
> - **за** + acc = *within* / *in* (time to finish): написа́л письмо́ **за** час.
> - **на** + acc = *for* (intended length): прие́хал **на** неде́лю.
> - **че́рез** + acc = *after / in* (an interval from now): верну́сь **че́рез** неде́лю.
> - Duration without preposition (accusative): Я говори́л с ней **10 мину́т**. («как до́лго?»)
> - Past-tense narration also uses **… спустя́**: час **спустя́** она́ верну́лась.

## 2. Prepositions вне, внутри (+ genitive)

- **вне** + *gen* = outside, out of (= снару́жи / не в).
- **внутри́** + *gen* = inside, within.

| вне … | meaning | внутри́ … | meaning |
|---|---|---|---|
| вне о́фиса / до́ма | not at the office / home | внутри́ коро́бки | inside the box |
| вне конкуре́нции | unrivalled | внутри́ себя́ / меня́ | inside oneself (feelings) |
| вне зако́на | illegal, outlawed | внутри́ компа́нии | within the company |
| вне игры́ | out of the game / sidelined | внутри́ страны́ | within the country |
| вне (мое́й) компете́нции | outside my expertise | | |

## 3. Verbs governing к + dative

Verbs that take **к + dative**:

- вести́ (к результа́ту) · возвраща́ться / верну́ться (к нача́лу) · гото́виться / подгото́виться (к экза́мену)
- обраща́ться / обрати́ться (к врачу́ за сове́том) · относи́ться / отнести́сь (к ситуа́ции серьёзно)
- подходи́ть / подойти́ (к до́му, к пробле́ме) · приближа́ться / прибли́зиться (к фи́нишу)
- приводи́ть / привести́ (к успе́ху) · привыка́ть / привы́кнуть (к семе́йной жи́зни)
- прикаса́ться / прикосну́ться (к иску́сству, к руке́) · присоединя́ться / присоедини́ться (к друзья́м)
- стреми́ться (к успе́ху)

- Как ты **отно́сишься к** здоро́вому пита́нию? · Мы **приближа́емся к** фи́нишу.
- Он **обрати́лся к** врачу́. · К чему́ ты **стреми́шься** в жи́зни?

## 4. Verbs with the prefix пред- (*fore-, pre-*)

The prefix **пред-** adds the sense of *before / in advance / foreseeing*.

| Verb | Meaning | Example |
|---|---|---|
| предвкуша́ть | to look forward to (with pleasure) | Я **предвкуша́ю** о́тпуск на мо́ре. |
| предви́деть | to foresee, anticipate | Он **предви́дел**, что прое́кт бу́дет успе́шным. |
| предпринима́ть / предприня́ть | to undertake, take (steps) | Мы **предприня́ли** всё, что́бы успе́ть. |
| предлага́ть / предложи́ть | to offer, propose | Я **предложи́л** ей по́мощь. |
| предполага́ть / предположи́ть | to suppose, assume | Я **предполага́ю**, что бу́дет дождь. |
| предпочита́ть / предпоче́сть | to prefer | Я **предпочита́ю** ко́фе ча́ю. |
| предупрежда́ть / предупреди́ть | to warn, notify in advance | Он **предупреди́л**, что опозда́ет. |
| предска́зывать / предсказа́ть | to predict, foretell | Сино́птики **предсказа́ли** снег. |

## Connectors & useful constructions

- **отклада́ывать / отложи́ть на за́втра** — *to put off until tomorrow*: Не **отклада́й** дела́ **на за́втра**.
- **справля́ться / спра́виться со** (+ *inst*) — *to cope with, manage*: Как ты **справля́ешься со** стре́ссом?
- **жа́ловаться на** (+ *acc*) — *to complain about*: **жа́ловаться на** нехва́тку вре́мени.
- **нехва́тка** (+ *gen*) — *shortage / lack of*: нехва́тка вре́мени / воды́.
- **всё равно́ что** — *just the same as*: Жа́ловаться на нехва́тку вре́мени — **всё равно́ что** для ры́бы жа́ловаться на нехва́тку воды́.
- **уме́ть говори́ть «нет»** — *to be able to say "no"*.
