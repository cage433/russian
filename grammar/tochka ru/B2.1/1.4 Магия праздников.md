# B2.1 · 1.4 — Магия праздников

Theme: holidays, traditions, gifts.
Grammar: impersonal & passive constructions (безличные предложения); time prepositions перед / за / на / с / прежде чем; the modals можно / нужно / должен; verbs + instrumental (recap).

---

## 1. Безличные и пассивные предложения

### (a) Passive «-ся» vs active "they-form"

Two ways to describe an event, differing in **focus**:

| Construction | Type | Focus | Example |
|---|---|---|---|
| Пра́здник (nom.) **пра́зднуется…** | passive / impersonal (-ся) | on the **event**; formal, neutral | Но́вый год **пра́зднуется** 1 января́. |
| Пра́здник (acc.) **пра́зднуют…** | active ("they" — no subject) | on **who / how** celebrates; conversational | Э́тот пра́здник **пра́зднуют** по всему́ ми́ру, устра́ивая пара́ды. |

Same pair with **отмеча́ться / отмеча́ют**:
- Ма́сленица **отмеча́ется** как си́мвол весны́. ↔ Ма́сленицу **отмеча́ют**, украша́я дома́.

### (b) Other impersonal (subjectless) sentences

Russian has many sentences with **no nominative subject**; the logical subject (if any) is in the **dative**:
- **Dative + state word:** Мне **хо́лодно** / **ве́село** / **гру́стно**. Мне **ну́жно** идти́.
- **Weather / nature (3rd-sg neuter):** **Темне́ет.** **Похолода́ло.**
- **Смерка́ется, хо́чется, ка́жется** — verbs used only impersonally: Мне **хо́чется** спать.

## 2. Time prepositions: перед, за, на, с … до, прежде чем

| Preposition | Case | Meaning | Example |
|---|---|---|---|
| **пе́ред** | *inst* | (just) before | **пе́ред** Но́вым го́дом; **пе́ред** сном |
| **за** … **до** | *acc* … *gen* | X (of time) before an event | **за** час **до** нача́ла |
| **за** | *acc* | done within a period | сде́лать **за** день |
| **на** | *acc* | for (planned duration); on (a holiday) | уе́хать **на** неде́лю; **на** Но́вый год |
| **с** … **до** | *gen* … *gen* | from … to (a span) | рабо́тать **с** утра́ **до** ве́чера |
| **пре́жде чем** | + infinitive | before (doing sth) | **Пре́жде чем** сесть за стол, семья́ собира́ется. |

> [!tip] пе́ред vs до
> - **пе́ред** = immediately before (пе́ред уро́ком — right before the lesson).
> - **до** = any time before / until (до уро́ка — before the lesson, at some earlier point; до ве́чера — until evening).

## 3. Modals: можно, нужно / надо, должен, нельзя

| Word | Construction | Meaning |
|---|---|---|
| **мо́жно** | (+ *dat*) + inf | it's possible / allowed |
| **нельзя́** | (+ *dat*) + inf | not allowed / impossible |
| **ну́жно / на́до** | (+ *dat*) + inf | need to, must (necessity) |
| **не ну́жно / не на́до** | (+ *dat*) + inf | no need to |
| **до́лжен / должна́ / должно́ / должны́** | (**nom** subject) + inf | obligation — **agrees with the subject** |

- Здесь **мо́жно** фотографи́ровать? · Здесь **нельзя́** шуме́ть.
- Мне **ну́жно** купи́ть пода́рки. · Тебе́ **не на́до** волнова́ться.
- Ты **до́лжен** извини́ться. · Они́ **должны́** прийти́ во́время.

> [!note] нельзя́ + aspect
> - **нельзя́ + imperfective** = it's forbidden: Здесь **нельзя́ кури́ть**.
> - **нельзя́ + perfective** = it's impossible: Э́ту дверь **нельзя́ откры́ть** (it won't open).

## 4. Verbs governing the instrumental (recap of 1.1)

Holiday vocabulary reuses instrumental government heavily:
- **наслажда́ться** пра́здником, **дели́ться** впечатле́ниями, **обме́ниваться** пода́рками/пожела́ниями, **горди́ться** тради́циями, **украша́ть** дом (+acc) **цвета́ми** (+inst = *with*).
- Пе́ред столо́м семья́ собира́ется, чтобы **обменя́ться** тёплыми **пожела́ниями**.

## Connectors & useful constructions

- **пре́жде чем** + inf — *before (doing)*: **Пре́жде чем** отпра́виться в путь, посиди́м на доро́жку.
- **в кругу́ семьи́** — *in the family circle, among family*: Ве́чер прохо́дит **в кругу́ семьи́**.
- **с нетерпе́нием ждать** (+ gen) — *to look forward to*: Де́ти **с нетерпе́нием ждут** боя́ куранто́в.
- **загада́ть жела́ние** — *to make a wish*. · **бой куранто́в** — *the chimes (of the clock at midnight)*.
- **наполня́ться** (+ *inst*) — *to fill up with*: Дома́ **наполня́ются** ую́том и ра́достью.
- **устра́ивать** пара́ды / гуля́ния — *to hold/organize parades, festivities*.
